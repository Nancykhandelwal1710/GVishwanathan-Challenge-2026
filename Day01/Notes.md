# Day 1

## Problem 1: Two Sum

Topic:
Arrays + Hashing

Approach:
Used unordered_map to store previously seen elements and their indices.

Time Complexity:
O(n)

Space Complexity:
O(n)

Learning:
Hashing can reduce a brute force O(n²) solution to O(n).

## Problem 2: Remove Linked List Elements

Topic:
Linked List

Approach:
Traverse the linked list and remove nodes having the target value.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
Carefully handle deletion when the target node appears at the beginning of the list.
