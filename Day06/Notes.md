# Day 6

## Problem 1: Maximum Subarray

Platform:
LeetCode

Language:
C++

Topic:
Arrays, Dynamic Programming

Approach:
Used Kadane's Algorithm to maintain the current maximum subarray sum while traversing the array.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
Kadane's Algorithm efficiently finds the maximum sum contiguous subarray in linear time.
