# Day 16

## Middle of the Linked List

Platform:
LeetCode

Language:
C++

Topic:
Linked List, Two Pointers

Approach:
Used slow and fast pointers where the slow pointer moves one step and the fast pointer moves two steps to find the middle node.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
The slow and fast pointer technique is an elegant approach for solving many linked list problems efficiently.

## Construct Binary Tree from Preorder and Inorder Traversal

Platform:
LeetCode

Language:
C++

Topic:
Trees, Recursion

Approach:
Used preorder traversal to identify the root node and inorder traversal to divide the left and right subtrees recursively.

Time Complexity:
O(n)

Space Complexity:
O(n)

Key Learning:
Combining traversal orders with recursion allows efficient reconstruction of binary trees.
