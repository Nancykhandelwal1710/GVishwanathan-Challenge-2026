## Average of Levels in Binary Tree

Platform:
LeetCode

Language:
C++

Topic:
Trees, Breadth First Search (BFS)

Approach:
Performed level-order traversal using a queue and calculated the average value for each level.

Time Complexity:
O(n)

Space Complexity:
O(n)

Key Learning:
Level-order traversal is useful for processing tree nodes level by level and computing aggregate values.
