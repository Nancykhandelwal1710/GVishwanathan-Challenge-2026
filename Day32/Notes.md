# Day 32

## Find Numbers with Even Number of Digits

Platform:
LeetCode

Language:
C++

Topic:
Arrays, Mathematics

Approach:
Traversed the array and counted the number of digits in each integer. Incremented the answer whenever the digit count was even.

Time Complexity:
O(n × d)

Space Complexity:
O(1)

Key Learning:
Simple mathematical operations can efficiently solve array-based counting problems without requiring additional data structures.

Platform:

Language:
Python

Topic:
Simulation

## Maximize Active Section with Trade I

Platform:
Online Assessment / Interview Problem

Language:
C++

Topic:
Arrays, Sliding Window, Optimization

Approach:
Used an optimized sliding window approach to determine the best trade that maximizes the total active section after performing a single operation.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
Sliding Window is an effective technique for optimizing contiguous subarray problems while reducing time complexity from quadratic to linear.
