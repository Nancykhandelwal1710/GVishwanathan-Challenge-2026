## Linked List Cycle

Platform:
LeetCode

Language:
C++

Topic:
Linked List, Two Pointers

Approach:
Used Floyd's Cycle Detection Algorithm with slow and fast pointers to detect a cycle.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
The slow and fast pointer technique is highly useful for cycle detection in linked lists.

Platform:
LeetCode

## Remove Nth Node From End of List

Platform:
LeetCode

Language:
Python

Topic:
Linked List, Two Pointers

Approach:
Used two pointers with a fixed gap to locate and remove the target node in a single traversal.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
Maintaining a fixed gap between pointers helps solve linked list problems efficiently in one pass.
