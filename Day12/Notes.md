## Kth Smallest Element in a BST

Platform:
LeetCode

Language:
C++

Topic:
Binary Search Tree, Inorder Traversal

Approach:
Performed an inorder traversal and counted visited nodes until reaching the k-th smallest element.

Time Complexity:
O(n)

Space Complexity:
O(h)

Key Learning:
Inorder traversal of a BST visits nodes in sorted order, making it ideal for order-based queries.

## Flood Fill

Platform:
LeetCode

Language:
Python

Topic:
Graph, DFS

Approach:
Applied Depth First Search (DFS) to recursively recolor all connected cells having the original color.

Time Complexity:
O(m × n)

Space Complexity:
O(m × n)

Key Learning:
DFS is an effective traversal technique for solving grid-based connected component problems.
