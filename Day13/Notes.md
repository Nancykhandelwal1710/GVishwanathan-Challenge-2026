# Day 13

## Unique Paths

Platform:
LeetCode

Language:
C++

Topic:
Dynamic Programming

Approach:
Built a DP table where each cell stores the number of unique paths by summing the paths from the top and left cells.

Time Complexity:
O(m × n)

Space Complexity:
O(m × n)

Key Learning:
Dynamic Programming helps break larger problems into smaller overlapping subproblems.

## Path Sum

Platform:
LeetCode

Language:
Python

Topic:
Trees, DFS

Approach:
Used recursive Depth First Search to check whether any root-to-leaf path equals the target sum.

Time Complexity:
O(n)

Space Complexity:
O(h)

Key Learning:
Recursive tree traversal is effective for exploring all possible root-to-leaf paths.

## Valid Anagram

Platform:
LeetCode

Language:
Python

Topic:
Hashing, Strings

Approach:
Compared the frequency of characters in both strings using Python's Counter.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
Hash maps simplify character frequency comparison and are widely used in string problems.
