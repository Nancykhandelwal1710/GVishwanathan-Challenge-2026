# Day 4

## Problem 1: Best Time to Buy and Sell Stock

Language:
C++

Topic:
Arrays, Greedy

Approach:
Traverse the array while keeping track of the minimum price seen so far and calculate the maximum possible profit at each step.

Time Complexity:
O(n)

Space Complexity:
O(1)

Key Learning:
Maintaining running minimum and maximum values can optimize problems significantly.

## Problem 2: Min Stack

Language:
C++

Topic:
Stack, Design

Approach:
Used two stacks:
1. One stack stores all elements.
2. Another stack stores the minimum element at each stage.

Time Complexity:
Push: O(1)
Pop: O(1)
Top: O(1)
GetMin: O(1)

Space Complexity:
O(n)

Key Learning:
Auxiliary data structures can help achieve constant time operations efficiently.

## Problem 3: Watermelon

Platform:
Codeforces

Language:
C++

Topic:
Math, Implementation

Approach:
Check whether the given weight is even and greater than 2. If yes, the watermelon can be divided into two even positive parts.

O(1)

Space Complexity:
O(1)

Simple mathematical observations can lead to elegant and efficient solutions.
